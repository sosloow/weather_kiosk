# Weather Icons

This directory contains weather condition icons. Replace the placeholder files with actual weather icons:

## Required Icons:
- `sunny.png` - Clear/sunny weather
- `partly-cloudy.png` - Partly cloudy weather  
- `cloudy.png` - Overcast/cloudy weather
- `rain.png` - Rainy weather
- `snow.png` - Snowy weather
- `thunderstorm.png` - Thunderstorm weather
- `fog.png` - Foggy weather

## Icon Specifications:
- Format: PNG with transparency
- Size: 80x80px for current weather, 40x40px for forecast
- Style: Simple, clean icons that work well on dark backgrounds
- Colors: Should be visible on the dark theme (#0a0f1a background)

## Recommended Sources:
- Weather Icons by Erik Flowers
- OpenWeatherMap icons
- Custom SVG converted to PNG
- Simple line art style icons

The app will fall back to `cloudy.png` for any unmapped weather conditions.
